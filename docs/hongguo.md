# 红果漫剧集成状态

开发者 Rios敖丙。桌面0.2.11加入独立「红果漫剧」栏目：请求红果官网公开漫剧分类页面的服务端目录数据，展示海报、标题、总集数、网页可访问集数与分页。读取JSON，不执行抓取页面中的脚本。

选片后在敖丙视界所属的独立窗口内加载红果官方网页播放器。该窗口禁用Node、启用隔离与沙箱，登录由官网处理。不启动外部EXE或系统浏览器，不提取账号会话、签名密钥或解密媒体。官网限制、登录要求与实际可播范围保留。抽样210集剧目仅标注网页可访问3集，不能承诺全集可播。

开发机已在线读取两页目录，每页24条，分页首条不同。JS语法检查通过；未完成官方播放器的视频帧/音频实播验证，不能仅凭目录读取宣称播放已验证。此版是官网目录加应用内官方网页播放，不是敖丙原生播放器的全量内容API接入。

当前仅桌面实现此功能，安卓/华为/API19/Switch/iOS尚未接入，不能将此功能声明为全平台一致。原有频道与点播快照校验独立运行。官网结构可能变化，失败会显示错误，不伪造内容列表。
