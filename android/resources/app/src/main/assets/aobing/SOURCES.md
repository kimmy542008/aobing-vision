# 内置直播列表来源

频道地址来源：IPTV-org 公开频道列表 https://github.com/iptv-org/iptv
列表地址：https://iptv-org.github.io/iptv/countries/cn.m3u
快照日期：2026-10-29（Asia/Shanghai）。

live-snapshot.m3u 是默认央视精选，包括 CCTV-1、2、8、13、14、17；六条流在开发机网络上经 ffprobe 检出 H.264 / AAC，其中 1、13、17 为 1920x1080，2、8、14 为 1280x720，仍需在用户机顶盒及网络下实际验证。
live-candidates.m3u 是央视、卫视、少儿等常见频道的备选快照，未逐频道保证网络可用性。已经排除本机检查失败的 CCTV-1 地址及默认精选之外的宗教等条目。
快照只保存频道地址，不包含视频文件；观看仍需要联网。
可从设置中的直播配置窗口更换地址，从直播源选择器切换到备选快照或在线完整列表。
