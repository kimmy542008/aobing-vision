# 公共内容配置

开发者 Rios敖丙。catalog 保存安卓电视、华为APK、手机和平板、API19版本共用的内容快照。更新内容时需同步这些构建输入，并运行 `node scripts/check-catalog.mjs`；CI 会拒绝有差异的提交。M3U 的台标属性属于显示信息，允许各端不同，但频道名称、分组及地址必须一致。

桌面目录目前是同一清理快照的 JSON 表示，Switch 使用其中的全球频道子集，iOS 暂未移植直播，尚未做到全部平台内容与功能完全一致。后续更新必须先补齐这些差异再声明全平台一致。静态安装包不会因为 GitHub 数据更新自动替换本地快照，需要重新发布安装包。此约定不是实时源自动更新服务。

红果的客户端启动入口已撤回；没有确认可用的官方红果内容目录与播放接口，不能标为已接入。抖音云短剧媒资API不等于任意读取红果全站内容。
